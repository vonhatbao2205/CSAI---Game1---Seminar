Câu hỏi kiểm tra (1/2)

1
Vì sao một path từ root tới một leaf thắng chưa đủ làm lời giải cho game?
Một số edge do đối thủ chọn. Path đó chỉ là một diễn biến; agent cần policy để đáp lại mọi phản ứng.
2
Ở thế Q, những ô nào thuộc Actions(s)? Vì sao một ô trống chưa chắc là nước tốt?
Các ô 0, 1, 2, 4. Cả bốn đều hợp lệ, nhưng sau X2 thì O có thể ép X thua.
3
Agent chọn đều A, B, C; đối thủ chọn đều hai số trong mỗi hộp. Expected utility tại root là bao nhiêu?
Ba hộp có value 0, 2, 5, nên root bằng (0 + 2 + 5)/3 = 7/3.
Thử trả lời trước khi xem đáp án.
Câu 1: lời giải là một policy.
Câu 2: Actions chỉ kiểm tra luật.
Câu 3 là Game evaluation với agent chọn đều.

Có thể hỏi người nghe trước khi hiện đáp án.

Câu hỏi kiểm tra (2/2)

4
Trong game ba hộp, đối thủ chọn số nhỏ với xác suất 0,9. Agent nên chọn hộp nào?
Hộp B. Expected utility của A, B, C lần lượt là −40; 1,2; −3.
5
Root là MAX, có ba con MIN với các leaf (3, 12, 8), (2, 4, 6), (14, 5, 2). Root value và nhánh được chọn là gì?
Ba node MIN trả 3, 2, 2. Root bằng max(3, 2, 2) = 3, chọn nhánh đầu tiên.
Câu 4 về Expectimax, câu 5 về Minimax.
Câu 4: thay p = 0,9 vào ba đường V_A, V_B, V_C.
Câu 5: tính các node MIN trước, rồi lấy max ở root.

Cây ở câu 5 lấy từ CS188 Lecture 7, trang 18. Các câu còn lại dùng mô hình và ví dụ đã trình bày.

Mời đặt câu hỏi

Một số câu hỏi có thể gặp.

Expectimax có luôn tốt hơn Minimax không? Chỉ khi mô hình về đối thủ đúng; tính chất ③ chỉ so sánh trong cột π₇.

Minimax có cần đối thủ chơi tối ưu thì lower bound mới đúng không? Không cần, chỉ cần agent giữ π_max.

Vì sao value trong Halving là ±∞? Chỉ để phân biệt thắng và thua; thay bằng ±1 vẫn được.

Game tree và state-space graph khác nhau thế nào? Tree giữ lịch sử, còn graph gộp các state giống nhau.
